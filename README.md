# AI Image Studio (Mojen reseller)

เว็บขายบริการสร้างภาพด้วย AI โดยใช้ Mojen AI เป็นผู้ให้บริการเบื้องหลัง
สมาชิกเติมเงินผ่าน Stripe เป็น credit แล้วใช้ credit สร้างภาพ ส่วนคุณ (admin)
ตั้งต้นทุนและ % กำไรของแต่ละโมเดลได้เอง

สแตก: Next.js 15 (App Router, TypeScript) · MySQL (XAMPP) · Stripe Checkout · Google OAuth

## เริ่มใช้งาน
1. เปิด MySQL ใน XAMPP Control Panel
2. `npm install`
3. `npm run db:init` — สร้าง/อัปเดตตาราง และ seed โมเดล + แพ็กเกจเริ่มต้น (รันซ้ำได้)
4. `npm run dev` แล้วเปิด http://localhost:3000
5. สมัครด้วยอีเมลเดียวกับ `ADMIN_EMAIL` เพื่อได้สิทธิ์ admin แล้วเข้า `/admin`

## การเพิ่มโมเดลใหม่
1. เปิดหน้า feature ที่ต้องการบน mojen.ai แล้วคัดลอก URL (มี `feature_xxxx`)
2. `/admin/models` → "เพิ่มโมเดล" → วาง URL ในช่อง Feature UID (ระบบดึง id ให้เอง)
3. ใส่ต้นทุน coin ตามที่ Mojen แสดง แล้วตั้ง % กำไร — ดูกำไรต่อภาพได้ทันที
4. ถ้าโมเดลมีพารามิเตอร์อื่นนอกจาก `seed` / `text_0` / `img_ref_0` ใส่เป็น JSON ในช่อง "พารามิเตอร์เพิ่มเติม"

## สูตรราคาและกำไร
```
ราคาขาย (credit)  = ceil(cost_coin × (1 + profit_percent / 100))
รายได้ต่อภาพ (฿)  = ราคาขาย × thb_per_credit
ต้นทุนต่อภาพ (฿)  = cost_coin × coin_cost_thb
กำไรต่อภาพ (฿)    = รายได้ − ต้นทุน
```
`coin_cost_thb` คือราคาที่คุณซื้อ coin จาก Mojen จริง ตั้งในหน้าตั้งค่า (มีปุ่มอ้างอิงแพ็กเกจ Mojen)
รายงานนับเฉพาะงานที่สำเร็จ งานที่ล้มเหลวและคืน credit แล้วจะไม่ถูกนับ

## Flow เงิน
- สร้างภาพ: ตรวจเงื่อนไขโมเดล → หัก credit → เรียก Mojen → ถ้าล้มเหลวคืน credit อัตโนมัติ (กันคืนซ้ำ)
- เติมเงิน: Stripe Checkout → webhook `checkout.session.completed` → เพิ่ม credit (กันเติมซ้ำ)
- ทุกการเปลี่ยน credit บันทึกในตาราง `transactions`

## .env
| ตัวแปร | หมายเหตุ |
|---|---|
| `MOJEN_API_KEY` | คีย์ Mojen |
| `DB_*` | MySQL (XAMPP default: root / ว่าง) |
| `AUTH_SECRET` | **ต้องเปลี่ยน** เป็นสตริงสุ่มยาวก่อนใช้งานจริง |
| `ADMIN_EMAIL` | อีเมลที่จะได้สิทธิ์ admin อัตโนมัติ |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | redirect URI: `<APP_URL>/api/auth/google/callback` |
| `STRIPE_SECRET_KEY` / `STRIPE_WEBHOOK_SECRET` | webhook: `<APP_URL>/api/billing/webhook` |
| `APP_URL` | ต้องเป็นโดเมนสาธารณะเพื่อให้ Mojen ดึงรูปอ้างอิงที่อัปโหลดได้ |

ค่าธุรกิจ (อัตรา, โบนัส, ประกาศ ฯลฯ) ตั้งในหน้า `/admin/settings` ไม่ต้องแก้ `.env`

ทดสอบ webhook บนเครื่อง: `stripe listen --forward-to localhost:3000/api/billing/webhook`

## ข้อควรรู้
- รูปที่อัปโหลดเก็บใน `public/uploads/` ตอนรันบน localhost เซิร์ฟเวอร์ Mojen ดึงรูปเหล่านี้ไม่ได้ ต้อง deploy หรือใช้ ngrok แล้วตั้ง `APP_URL`
- อย่ารัน `npm run build` ระหว่างที่ `npm run dev` เปิดอยู่ (ใช้โฟลเดอร์ `.next` เดียวกัน) ถ้าเจอ error `Cannot find module './vendor-chunks/...'` ให้หยุด dev ลบ `.next` แล้วรันใหม่
